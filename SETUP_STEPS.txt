SETUP STEPS
========================================================================

--- FOR DELETE + EDIT BOOK FEATURE (new) ---

1. Overwrite these files with the versions in this zip:
   - library/urls.py        (new delete-book, delete-member, edit-book routes)
   - library/views.py       (new delete_book, delete_member, edit_book views;
                              all_books/all_members now also return "id")
   - templates/books.html   (Add Book modal heading now has an id, reused
                              for editing)
   - templates/settings.html (new "Delete Records" section at the bottom)
   - static/books.js        (Edit button now opens the Add Book modal
                              pre-filled and saves changes)

2. No migrations needed — no model fields changed, only view/route logic.

3. Test it:
   - Books page -> click "Edit" on any book -> modal opens pre-filled ->
     fix the title/author or paste a new cover image URL -> Save Changes.
   - Settings page -> scroll to "Delete Records" -> pick a book or member
     from the dropdown -> Delete.

IMPORTANT NOTES:
- A book currently borrowed (not yet returned) can't be deleted until it's
  returned — this stops orphaned borrow records.
- A member with an active unreturned borrow also can't be deleted for the
  same reason.
- Deleting a member who has a linked login account also removes that
  linked User row, so they can no longer log into the member portal.
- static/members.js and templates/members.html are UNCHANGED from what
  you already have — delete for members lives in Settings now, not as a
  per-row button, so nothing there needed touching.

HOW TO APPLY
-------------
Open each file in this zip, copy its full content, and paste it over the
matching file in your GitHub repo (Edit -> select all -> paste -> Commit
changes). Then on PythonAnywhere:
   cd ~/canopy
   git pull origin main
...then reload the web app from the Web tab.
